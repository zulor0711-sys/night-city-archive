# 夜之城档案 / NIGHT CITY ARCHIVE

一个关于《赛博朋克 2077》的互动审美实验 —— 可以直接在线交互。

**在线页面：** https://zulor0711-sys.github.io/night-city-archive/

## 里面有什么

8 个章节：接入 / 城市 / 宣言 / 七区 / 记忆 / 义体 / 塔罗 / 印象

5 类交互：

- **七区勘测图** —— 点哪个区，地图、档案面板、整节配色一起变，附 NCPD 官方威胁评级
- **超梦编辑器** —— 拖时间轴检索记忆，视觉 / 音频 / 热成像三层可独立开关
- **义体装配台** —— 装得越多，人性残值掉得越快，画面越来越红、开始抖
- **二十二张塔罗** —— 牌面符号由种子算法现场绘制
- **屏蔽文字** —— 悬停揭开被删改的段落

支持桌面 Chrome / Edge 与手机浏览器，纯静态、无需联网依赖。
